

\# Contribute



We welcome contributions that make scientific results easier to reproduce and independently evaluate.



\## Ways to contribute



\- Reproduce a result reported in a scientific paper.

\- Implement an independent numerical method.

\- Compare computed values with published tables, figures, or reference data.

\- Improve execution instructions or automated tests.

\- Review equations, assumptions, convergence evidence, and numerical discrepancies.

\- Report limitations or failed reproduction attempts.



\## What to include



A useful submission identifies the publication and target result, provides the implementation and execution instructions, records numerical parameters, and explains how the output was compared with the reference.



Please distinguish published values from newly computed values. Report failed runs and discrepancies honestly; they are valuable evidence.



\## Current development stage



The platform is under development. The initial priority is to establish a rigorous, transparent verification record using the Shu (1977) benchmark before expanding to additional papers.



For now, contributions should be made through the project's GitHub repository and reviewed before inclusion.
